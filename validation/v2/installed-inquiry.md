**不能按字数换算，因为可见字符、码点、字节和 token 是不同的计数单位，彼此没有固定比例。**

- **Core｜文本表示机制：**一个可见字素可能由多个 Unicode 码点组成，每个 Unicode 标量值在 UTF-8 中占 1–4 字节。汉字并非一律占 3 字节，一个可见 emoji 也不一定只有一个码点。见 [[V2 Smoke - Unicode、UTF-8 与可见字素|V2 Smoke - Unicode、UTF-8 与可见字素]]。
- **Core｜token 切分机制：**卡片以字节级 BPE 为例：文本先表示为 UTF-8 字节，再按 tokenizer 已固定的词表与合并规则切分。一个 token 可以覆盖多个字符，也可能只覆盖一个字符的部分字节。因此，即使知道字数或字节数，也不能直接推出 token 数。见 [[V2 Smoke - Tokenization 与字节级 BPE|V2 Smoke - Tokenization 与字节级 BPE]]。
- **FYI｜具体例子：**`中`占 3 字节，`😀`占 4 字节；`👩‍💻`通常显示为一个字素簇，却包含 3 个码点、11 字节。这些是编码实例，**不是 token 数**。卡片记录这些编码和长度曾用 Python 检查。见 [[V2 Smoke - Unicode、UTF-8 与可见字素|V2 Smoke - Unicode、UTF-8 与可见字素]]。另一张卡的模型版本与词表示例明确标为“未作外部核验”，不能作为当前模型配置的证据。
